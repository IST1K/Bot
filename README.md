# Bot Control Panel

> Графическая панель управления ботом для Minecraft на Python и Mineflayer

## можно управлять ботом через панель 

##  Основные возможности
**Управление движением:** ручной контроль перемещения бота (W, A, S, D).
**Автоматический поиск ресурсов:** поиск и добыча руд (включая алмазы).
**Боевой модуль (PvP):** автоматическое ведение боя с мобами или игроками.
**Графический интерфейс (GUI):** удобная панель с выводом логов и текстовых сообщений в реальном времени.
**Многопоточность:** параллельная работа интерфейса и логики бота без задержек и зависаний.

| Технология / Библиотека | Назначение |
| :--- | :--- |

## Требования к системе
Перед запуском проекта убедитесь, что в вашей системе установлены следующие компоненты:
1. Python версии `3.10` или выше[cite: 1].
2. Node.js версии `18.x` или выше (необходим для работы связки `javascript` в Python)[cite: 1].
3. Сервер Minecraft версии `1.21.1` (локальный или сетевой)[cite: 1].
